# <img src="assets/icon.png" width="28" align="absmiddle" /> QR Scanner (Beta)

[简体中文](README_zh.md)

A Windows system tray screen QR code and barcode scanner written in Rust. Left-click the tray icon and drag to select a region on your screen to recognize QR codes and common 1D/2D barcodes (with English & Simplified Chinese UI support).

## Build

```powershell
cargo build --release
```
