# <img src="assets/icon.png" width="28" align="absmiddle" /> QR Scanner (Beta)

[English](README.md)

Windows 托盘屏幕二维码与条形码扫描工具，左键点击托盘图标框选屏幕即可识别二维码及常见一维/二维条形码（支持中英文界面切换），基于 Rust 编写。

## 构建

```powershell
cargo build --release
```
